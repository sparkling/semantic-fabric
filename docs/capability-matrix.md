## Release-blocking limitations

- **l-authz (ADR-0018)** — No production authentication, authorization, RLS or ABAC enforcement is implemented.
- **l-config-layering (ADR-0011)** — Environment-referenced source values exist, but the validated defaults/TOML/env/secret-store configuration model is not implemented.
- **l-deadline-cancellation (ADR-0010)** — Deadline expiry does not interrupt detached compiler CPU, in-flight SQLite work or establish common database-native statement cancellation.
- **l-describe (ADR-0038)** — DESCRIBE has compiler-only tests but no end-to-end backend or endpoint result evidence.
- **l-federation (ADR-0040)** — Snapshot-local source identity exists, but there is no registry, coordinator or multi-source production caller.
- **l-global-operators (ADR-0040)** — Serving rejects known source-sized ORDER, GROUP, solution/term DISTINCT and graph-dedup Rust fallbacks before source I/O; bounded physical implementations remain unavailable.
- **l-lateral (ADR-0007)** — The parser feature recognizes LATERAL, but both compiler paths reject it and no execution profile is implemented.
- **l-live-optional (ADR-0038)** — The PostgreSQL/MySQL evidence can skip on provider absence and therefore cannot establish production admission.
- **l-metadata-toctou (ADR-0038)** — Live result-column probes and branch emission fail closed before cursor I/O, but the sequential preflight can race later DDL and is not a coherent schema-generation lease.
- **l-mysql-mapping (ADR-0038)** — No sealed W3C RDB2RDF mapping execution matrix exists for MySQL.
- **l-mysql-source-test (ADR-0038)** — The MySQL source-selector branch lacks a positive open_backend selector test.
- **l-observability (ADR-0011)** — Production telemetry, health/readiness, graceful shutdown and lifecycle controls remain unimplemented.
- **l-path-resource (ADR-0049)** — Recursive property paths use an exact finite-pair fixed point, but total work/cancellation budgets and live PostgreSQL/MySQL qualification remain open.
- **l-postgresql-synthetic-row-identity (ADR-0007)** — Compiler-only no-primary-key path SQL maps the synthetic `rowid` sentinel to snapshot-local PostgreSQL `ctid`; a real `rowid` column still collides and live PostgreSQL path execution is not evidenced.
- **l-product-mock-live-drift (ADR-0048)** — Mutable product-mock PostgreSQL is an optional development differential. Its table/column inventory currently rejects drift and grants no backend admission.
- **l-production-admission (ADR-0038)** — The complete backend contract, live matrix, security, cancellation and conformance gates in ADR-0038 R3 are incomplete.
- **l-protocol (ADR-0019)** — No pinned SPARQL Protocol manifest is executed; only a tested read-only HTTP subset exists.
- **l-query-budget (ADR-0010)** — One absolute serve-layer deadline exists, but compiler work, rows, bytes, source work, recursion and native cancellation do not form one total QueryBudget.
- **l-release-artifact (ADR-0039)** — Narrow private diagnostics include same-byte static RootPie preflight, a counterfactual non-authority bubblewrap name/path inventory, and late seccomp; actual host byte consumption/runtime closure, the minimal production dependency closure, and exact-artifact release proof are not implemented.
- **l-schema-lifecycle (ADR-0007)** — Explicit-R2RML serving quarantines unverified constraints and type-authorized pooling, while live result-column preflight fails closed; coherent structural/type generations, typed synthetic row identity, atomic reload, verified optimisation and Direct Mapping regeneration remain unimplemented.
- **l-semantic-builder-gold-source-development (ADR-0048)** — Canonical semantic-builder gold and the sealed semantic-product-mock source are development authorities. The in-charter slice maps one table and proves neither image/source provenance nor backend admission.
- **l-snapshot (ADR-0038)** — Validated immutable snapshot reload and schema-drift readiness handling are not implemented.
- **l-stream-error-atomicity (ADR-0011)** — Post-200 SELECT/CONSTRUCT failures terminate the body and may expose a usable prefix; they cannot become RFC 9457 responses.
- **l-transport-security (ADR-0014)** — Remote-source TLS verification and a production secret-store transport remain unimplemented.
